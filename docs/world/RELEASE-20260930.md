## Corrections

- Leaving a kit bench now calls its existing `stand` action. Moving away, using again or
  changing rooms keeps the player pose and bench state consistent. Previously a bench stayed
  `sat` after movement, and its next use only stood the empty bench up.
- Clearing the Blade explicitly stops the rain-following storm driver. Visual rain still
  eases, but the old asymptotic tail no longer emits full-volume warning/gust cues.
- Normal visits now select only the phase 2 room graph. A visitor's phase 1 rest in
  `arrival/plain/house` falls back to A1, preserving flags, props, sound and the old rest for
  rollback. The legacy graph remains explicitly accessible through `?world=test`. Previously
  the shared save key could strand a returning visitor in the old three-room test world.
- The recovered music-entry/rest fixes, lift muffle ramp, Blade hush, player lighting,
  summon seals, archive product links, sprite probe, seated clip, lamp points and story API
  are retained. These were already in source despite the old runtime document listing them
  as open.
- Browser recorders now fail on unsuccessful observations. The sit fixture uses the C1
  street floor, rather than putting the player on the upper walkway; it checks a second sit
  on one use. The storm fixture monitors the first uninterrupted Blade crossing. The round
  verdict checks the 27 ordered checkpoints, saves, shortcuts, ending, flash gate and
  scroll-away; Stonetop remains an optional branch.
- Capture runs own their server process and validate an instance nonce so a different
  process on the same port cannot supply false proof. CPU/SwiftShader is an explicit source
  route; D3D/native acceptance belongs to delivery.
