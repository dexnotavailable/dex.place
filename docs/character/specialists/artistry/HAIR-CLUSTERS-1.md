## Construction decision

Actual inspection included all 17 human reference files, genuine R2 at native
144/80, and the earlier authored reconstruction finish. References remain
fixed 9/10 anchors; their raster pixels are never module inputs. Animation
reference sheets/static previews were inspected as stills, not played motion.
The useful craft cue is coherent connected hair shapes with a readable face
and restrained specular accents. This letter changes no face expression.

The earlier broad reconstruction finish reduced tone counts across seven
materials but produced only a small documented face advantage at144 and a
near tie at80. This method acts on connected topology within a modeled hair
part instead of repeating that global reduction or rejected Face2/collar/
headtilt trials.

## Authored method

`cluster_finish.finish(control, ids, light, meta, cfg, stage=None)` is an array interface.
`control` is the exact finished R2 RGBA at native size. `ids` and `light` are
the matched supersampled native categorical and lighting passes. An exact
color fragment of up to six pixels at144 or two at80 may merge into an
adjacent, at least twice-as-large color component within the same modeled
hair part, with at least two cardinal boundary contacts. The receiving
component exceeds the small-fragment limit and never itself moves.

Only fully covered same-material cells with a one-pixel material interior
halo are eligible in native replay mode. Part assignment follows native F1's
weighted-mode rule (one-material weights are constant; first-subpixel tie
break), with zero mismatches required in the finite proof. A synchronous,
try/finally-restored wrapper captures actual R2 semantic labels and protected
face/outline/occlusion cells at the original hair-clump stage. Its separator
selection uses that exact processed pre-clump lightness, left/top equality
ties, native N8 connectivity and minimum run2. The selected count must equal
the unchanged R2 function's result. Selected cells are protected even when
their blend produces no visible RGB delta. Standalone calls without a matched
stage retain the stricter whole-part halo. Material
AA boundaries, exact hair clump separators and outline
are protected. The anchor-derived face box and the original hair sheen core
and halo are protected. Replacements must meet bounded OKLab lightness/color
distance and reuse an existing RGB from that same native part. No new ramp,
noise, blur, downsampled reference, generative raster or screen-coordinate
drawing stamp enters the result. One synchronous pass prevents iterative
erosion. All alpha bytes, dimensions and every outside-scope byte stay exact.

This is not a global palette cap. Face, skin, white, gold, indigo clothing,
azure coverage, pose, geometry, chest opening, grip, ground and silhouette
remain the matched control. A raw nearest-sample image is a labeled diagnostic
of existing supersampled native passes; it is never used as candidate input.

## Finite replay

Run under the packet shared resource gate as `rosace-artistry-source`:

```powershell
python art/rosace/specialists/artistry/cluster_finish.py `
  --root <preserved-R2-raw-root> `
  --out <this-worktree>/review/rosace/artistry/<fresh-letter>
```

The root contains `idle/px144` and `idle/px80`, nine matched raw/metadata files,
and preserved `R2/still.png` plus `R2/still_ground.png`. Both transparent and
grounded R2 controls must replay at zero changed pixels. A pre-existing or
overlapping output is rejected. Output must be inside this executing
worktree's private `review/rosace` directory.

Proof records raw/config/module hashes, exact per-fragment before/after RGB
and coordinates, native masks, changed pixels, face/sheen preservation,
same-clump palette subsets and connected-component/color counts. Whole and
hair/face views at1x are the visual acceptance surface;4x/6x nearest views
are diagnostics. Source checks do not establish attractive art.

The first diagnostic required every subpixel to share an identical part as
well as material. It was a no-op at144/80: eligible pixels34/0, changed0/0.
Preserved proof/module/config remain in the private `hair-clusters-1` folder.
The second diagnostic used native dominant parts but kept the whole part edge
halo: changed4/0 pixels at144/80. The third changes the masking method to exact
R2 separator/occlusion protection: changed5/0, connected components279->277
at144,104->104 at80. It preserves zero control differences, label mismatches,
alpha/outside/face/sheen/native-protected changes. This is a neutral source
diagnostic at actual1x, not demonstrated visual improvement;80 is a no-op.

## Acceptance and handoff

The lane's packet PREVIEW and proof provide actual results and their honest
verdict; source stays opt-in if the visible difference is neutral or weaker.
Three fresh actual-pixel critics belong to `rosace-critics` and must judge
the materially new candidate at144/80 against fixed human anchors. No score,
reference parity or promotion is inferred from lower component counts.

An integration consumer may call the array function only after its own exact
control qualification, source conflict review and actual acceptance. The
integrator records the result/commands/limits in shared `PIPELINE.md`; this
specialist has no write ownership there. No Blender call is needed to compare
this still letter on preserved raw pixels. View/pose/moving sprite evaluation,
physical sleeves/tabards, collision, transitions and playback remain native
delivery dependencies. Current motion finish lacks this matched native
input contract; no motion compatibility is claimed.

Rollback: omit this optional function and keep exact R2. No state map,
original pixels, model, default builder, frozen request or rollback file is
modified. Shared R2 rollback manifests are preserved separately in the lane
packet; reversing a source integration removes only this namespace letter.
