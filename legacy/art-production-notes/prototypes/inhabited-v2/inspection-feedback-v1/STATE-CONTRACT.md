# Physical inspection feedback

Implementation: WorldScene + assemblies. UI close/browse sends `close-inspection`. No new download, payment, cut, travel or account action is introduced by this presentation.

| Origin | While its inspector is open | Return |
|---|---|---|
| Terminal / product terminal | Source screen brightens and its status insert stays active. Product reuses the terminal material path. | Screen/status return over220ms. |
| Physical folder | Fixed native P12 back remains on the floor; a separate cropped cover reveals12 rows and the paper inset rises3 pixels over160ms. | Cover and inset settle back over220ms. |
| Artwork frame | A local warm rim/corner response holds around the originating generated frame. Personal artwork remains unchanged in DOM. | Rim returns over220ms. |
| Donation plinth | A restrained plaque/cap response holds while Donate is inspected. | Plaque/cap light returns over220ms. |

Only these inspectable assembly kinds enter `panel_active`/`returning`. Existing cut, bridge, map, lift, door and physics states retain their existing owners. A new inspection releases the old origin first. Navigating inside one reader retains its originating physical object until that inspector closes; it does not remotely trigger other objects.

The display timeline advances independently from gameplay while the document is visible. Gameplay remains paused by the normal panel input owner. Hidden-document presentation time is frozen. Blur does not automatically close/reopen the inspector or fire an action. Reduced motion applies the final display state immediately. Close/browse starts the return; Resume is a fallback release. Room replacement and renderer disposal clear held/returning inspection visuals without mutating hardware or progress. A grounded, unhurt hero with no active sword swing settles into its existing idle pose facing the inspected source; position and active sword follow-through are preserved.

`prepared` is a distinct room-transition phase emitted whenever passage assets finish hydrating. The source room is still visible and Resume is allowed. The ordinary playing UI suppresses its brief label. Opening is announced only from a resumed simulation tick; completed transfer still emits `ready`. Announcing readiness independently of focus also closes the race where Menu opens between hydration and the next simulation tick.
