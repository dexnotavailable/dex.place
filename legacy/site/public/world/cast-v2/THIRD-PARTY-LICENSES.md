# Third-party sprites in this folder

Added during the legacy import (2026-09-28) so the license record travels with the files in the public repo. Every sprite here is an unmodified original frame sheet from a free CC0 pack. `manifest.json` in this folder records the creator, license and source page for each actor and prop.

| Folder / file | Pack | Creator | License | Evidence kept with the files |
|---|---|---|---|---|
| `wizard2/` | Evil Wizard 2 | LuizMelo | CC0 1.0 | `wizard2/LICENSE.txt` (the pack's own License.txt) |
| `rat/`, `bat/` | Monsters Creatures Fantasy 2 | LuizMelo | CC0 1.0 | The pack ships no license file. The creator page (https://luizmelo.itch.io/monsters-creatures-fantasy-2) states CC0; rechecked 2026-09-28. |
| `townsfolk1/` to `townsfolk4/` | GothicVania Town | Ansimuz (Luis Zuno) | CC0 1.0 | The pack's license PDF grants CC0 to all package art (https://ansimuz.itch.io/gothicvania-town). Only the four NPC sheets are here. The pack's music uses a different license and was never included. |
| `small-fire.png` | Animated Fires | Stealthix | CC0 1.0 | The creator page (https://stealthix.itch.io/animated-fires) states CC0. |
| `ui/steel-frame.png`, `ui/paper-frame.png` | UI Pack - Pixel Adventure 2.0 | Kenney | CC0 1.0 | `ui/LICENSE.txt` (the pack's own License.txt) |

CC0 1.0 legal code: https://creativecommons.org/publicdomain/zero/1.0/
